# Lumen · Quiet Heritage — complete kit

Everything created so far, in build order.

- tokens/ — tokens.css (CSS variables, Paper + Evening), tailwind.theme.js, tokens.json (source of truth)
- design-system/ — the Quiet Heritage system source: README brand book, components/bundle.js + bundle.css + index.d.ts, per-component README and preview, asset-group READMEs, exports/
- brand/ — Lumen identity (logos, monogram, favicons, app icons), icons/ (47 + sprite), motifs/, guides/, placeholders/, illus/, empty/, motion/ (loader, CSS, spec), og.png, devpost-cover.png, devpost-thumb.png, table-card.pdf/.png
- brief/ — Design Brief LUM-0042 (PDF + HTML + previews), Session Report, react-pdf-spec.md, DesignBrief.tsx, fonts/
- emails/ — four HTML emails, screenshots, README of subjects and placeholders
- copy.en.json — UI microcopy dictionary with 6 Hindi accent moments
- screens/ — source of the client-journey and atelier-dashboard canvases (.dc.html). They reference the canvas's uploaded images by /_blob/ id and the system copy under ds/quietheritage/, so they render inside the canvases, not standalone.
- deck/ — the 8 pitch-deck slides and deck.json (same note: images are /_blob/ ids in the deck)
- art/ — AR camera and 3D-viewer stand-in drawings used in the screens
- data/catalog.json — the fictional catalogue (names, codes, weights, prices)
- sheets/ — contact sheets for icons, motifs and illustrations

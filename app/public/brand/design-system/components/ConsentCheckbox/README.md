# ConsentCheckbox

A checkbox row for consent (camera use, reminders), with the whole row as a 44px+ target.

- **Props:** `checked` / `defaultChecked`, `onChange(checked)`, `required` (adds “(required)”), `error`, `disabled`, `children` (the sentence; may include a `TextLink`).
- Write the consent as a full sentence in the first person: “I agree to the atelier using my camera for this try-on.” Say what is and isn’t stored.

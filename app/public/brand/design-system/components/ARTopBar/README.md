# ARTopBar

The Evening top bar over the camera: close, piece name, and the Rough preview badge.

- **Props:** `pieceName`, `detail` (small caps, e.g. “22K yellow · ruby”), `onClose`, `closeLabel`, `rough` (false hides the badge; don’t).
- Sits on `surface-control` with a gold hairline beneath. The name truncates before the badge ever shrinks.

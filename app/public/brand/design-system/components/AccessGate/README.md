# AccessGate

The invitation gate: atelier name, a rare Devanagari welcome, “A private viewing”, the access-code field and Enter.

- **Props:** `atelier` (the client’s name), `onSubmit(code)`, `error`, `busy`, `onRequest` / `requestHref` (“Request an invitation”), `title`, `lead`, `accent` (a Devanagari word, or false), `defaultCode`.
- The code uppercases as typed and Enter enables at 4+ characters. Paper mode, 390 mobile first; centre it in the 12-column grid on desktop at 4 columns wide.

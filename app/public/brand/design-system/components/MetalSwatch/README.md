# MetalSwatch

A flat metal disc (yellow, white, rose gold) for choosing the metal, same sizing and states as `StoneSwatch`.

- **Props:** `metal` `"yellow" | "white" | "rose"`, `selected`, `onSelect`, `showLabel`, `disabled`.
- Use inside `SwatchGroup kind="metal"`. In Paper screens prefer `SegmentedControl` with metal dots when a text label helps; in the AR rail use swatches.

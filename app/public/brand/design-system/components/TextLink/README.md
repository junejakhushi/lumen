# TextLink

An inline link whose gold underline draws in from the left on hover and focus (480ms, `ease-draw`).

- **Props:** `href`, `children`, `disabled`, `state` (docs only), native anchor props.
- At rest it keeps a `hairline-quiet` underline so it never relies on colour alone.
- Use for navigation and secondary actions inside copy (“View the full specification”, “Request an invitation”). Don’t use for the primary action.

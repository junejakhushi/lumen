# FilterChip

A pill that toggles one filter on or off (`aria-pressed`).

- **Props:** `selected` / `defaultSelected`, `onChange(selected)`, `count` (optional number), `disabled`, `children` (the label).
- Selected chips invert to `text` fill with `text-inverse` label and a check. 44px tall.
- Use for collection filters (Jhumkas, Chandbalis, Polki, Pearls, Peacock). For one-of-many choices use `SegmentedControl`.

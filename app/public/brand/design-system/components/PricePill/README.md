# PricePill

The indicative price as a hairline pill: “Indicative ₹1.4–1.7L”.

- **Props:** `low`, `high`, `unit` (`"L"` lakh default, or `"K"`), `currency` (default ₹), `label` (default “Indicative”), or `children` for a custom string.
- Always a range, always labelled indicative. Screen readers hear “Indicative price 1.4 to 1.7 lakh rupees”.

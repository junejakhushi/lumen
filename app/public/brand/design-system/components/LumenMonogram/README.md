# LumenMonogram

The Lumen monogram: an L drawn as one unbroken gold wire that ends in a small round stone.

- **Props:** `size` (px; at 20 or below it switches to the pixel-fitted 16-grid drawing without the top curl), `title`.
- Stroke only, never filled. Wire colour is `control-line` (gold-deep on Paper, gold on Evening).
- Use for the favicon, the app icon, the AR top bar’s leading mark and anywhere the full lockup won’t fit.

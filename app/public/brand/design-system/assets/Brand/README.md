# Brand

Lumen identity files. Letters are outlined Cormorant SC 500; the atelier line in `*-atelier*` files is live text with Jost Light embedded (open the SVG and change “for The Atelier”). Wire and monogram strokes: 1.25px / 1.5px at 1x.

- Suffix `-ivory`: on an ivory (#F5F0E8) ground, ink letters, gold-deep (#8C6C3A) wire.
- Suffix `-ink`: on an ink (#1B1916) ground, ivory letters, gold (#A8844A) wire.
- No suffix: transparent, for light backgrounds (ink letters, gold-deep wire). `-reversed`: transparent, for dark backgrounds (ivory letters, gold wire).
- `monogram.svg`: transparent, gold (#A8844A) wire, which reads on both ivory (3:1) and ink (5:1).
- `favicon.svg` switches between ivory and ink tiles with `prefers-color-scheme`. `favicon-32.png` is the fallback.
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` (180): ink ground, full bleed, monogram in the central safe zone (maskable-safe). `-ivory` versions for light launchers.
- `app-icon-ink.svg`, `app-icon-ivory.svg`: the vector sources for the icons.

# Motifs

Quiet Heritage ornament as editable SVG line art: stroke #A8844A (`gold`), 1px at 1x, round caps and joins, no fills. Recolour by editing `stroke`. Marks, frames and the jaali use `vector-effect="non-scaling-stroke"`, so the line stays 1px at any display size.

- `divider-plain|bead|paisley-120|240|480.svg`: gold-thread dividers in three lengths.
- `jaali-tile.svg`: seamless 256×256 lattice. Use only at 4–6% opacity as a background.
- `mark-peacock|paisley|lotus|jhumka.svg` (160px) and `-48.svg` (48px, simplified): each is one continuous path.
- `frame-arch.svg` (mehrab outline, 320×480), `frame-corners.svg` (bracket pair, 320×480), `frame-corner.svg` (one bracket, 56×56).
- `seal-hallmark.svg` (120px): outlined Cormorant SC lettering. Use only on genuinely hallmarked and certified pieces.

# Icons

47 line icons, 24×24, 1.25px stroke, round caps and joins, drawn in `currentColor` (these tiles show them in black, since an `<img>` can’t inherit colour). Inline the SVG or use `sprite.svg` (`<svg width="24" height="24"><use href="sprite.svg#qh-<name>"/></svg>`) so the icon takes the text colour; in React use `Icon name="<name>"`.

Try-on and capture: ar-try-on, camera, flip-camera, snapshot, 3d-rotate, compare. Jewellery: necklace, choker, earring-jhumka, earring-stud, bracelet, bangle, ring, pendant, maang-tikka, set. Attributes: metal, karat, stone, size, length, weight, budget-rupee, hallmark-shield. Booking and contact: calendar, clock, studio-visit, video-call, chat, phone, email, location-pin. Actions and system: save-look, share, download-pdf, undo, check, close, info, chevron-up/down/left/right, filter, search, lock, eye-off.
